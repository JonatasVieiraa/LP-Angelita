# Santinho Online - Angelita

Projeto de "santinho" online desenvolvido para candidatos compartilharem suas propostas de forma elegante e exclusiva.
O Layout foi focado para atender com maior qualidade os dispositivos mobile.

## Como Rodar

1. Clone o repositório:

    ```bash
    git clone https://github.com/JonatasVieiraa/LP-Angelita.git
    ```

2. Navegue até o diretório:

    ```bash
    cd LP-Angelita
    ```

3. Abra `index.html` em seu navegador para visualizar o santinho.

## Estrutura do Projeto

- **index.html**: Estrutura do santinho online.
- **styles.css**: Estilos para um design elegante e exclusivo.
- **script.js**: Funcionalidades adicionais ou interações.
